## Référentiel V0.1

CAP-002 donne à une personne un accès personnel à DG Afrique : création gratuite du compte, connexion, vérification de l'accès et entrée dans Mon espace. Le compte reste distinct de l'adhésion ZUMRA et constitue une porte d'accès, pas une adhésion automatique aux programmes.

## Corrections DG déjà réalisées

### Renvoi du code

DG envoie maintenant le contrat Core courant :

```json
{"identifiant_reference":"RID-...","destination":"personne@example.com"}
```

### Retour après connexion

`safeAccountReturnPath()` accepte uniquement un chemin local DG. `//`, URL/schéma externe et boucle `/connexion` sont refusés. Le login et la vérification reprennent ensuite cette destination.

### Vérification interrompue

Le dossier local `dgafrique_pending_account_verification_v1` conserve uniquement identité Core opaque, RID, référence de vérification, email et échéances. Aucun mot de passe ni code n'est persisté. Le dossier peut permettre un renvoi après expiration de l'ancien code et expire après 7 jours.

### Premier email non livré

`VERIFICATION_NON_LIVREE` conserve maintenant les références du compte déjà créé afin de permettre le renvoi sur la même identité plutôt que de tenter une nouvelle création.

### Limitation login

Core 429 est présenté comme limitation de tentatives et non comme indisponibilité générique.
