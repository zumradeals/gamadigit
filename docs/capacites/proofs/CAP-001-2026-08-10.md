## 1. Contrat Core audité

`CAP-CORE-001 / CTR-01` reste l'autorité canonique de l'identité personne. DG Afrique résout cette identité via `GET /identites/{reference}` sous session Core et ne crée pas d'identité canonique concurrente dans Supabase.

Références auditées :

- `zumradeals/gamad-core:core/registre-identites/src/Ctr01.php`
- `zumradeals/gamad-core:apps/console-laravel/app/Http/Controllers/Ctr01Controller.php`

## 2. Session portail DG Afrique

La session portail contient uniquement le support technique nécessaire : token Core, référence d'entité, assurance et expiration. Le cookie est signé côté serveur, HttpOnly, Secure, SameSite=Lax et borné au portail.

La primitive `src/lib/gamad-core/portal-session.ts` est testée pour :

- session intacte et non expirée acceptée ;
- payload altéré refusé ;
- signature altérée refusée ;
- session expirée refusée ;
- secret de signature différent refusé ;
- cookie malformé ou incomplet refusé.

## 3. Session invalide vs panne transitoire

`/api/genesis/account/me` utilise la primitive `src/lib/gamad-core/identity-state.ts` :

- Core `401` → `authenticated=false`, HTTP 401, cookie portail effacé ;
- autre panne → HTTP 503, `authenticated=true`, cookie conservé, erreur `IDENTITE_TEMPORAIREMENT_INDISPONIBLE`.

## 4. Point d'attache métier Supabase

L'audit structurel confirme que les objets métier ZUMRA existants utilisent `core_identity_reference` comme point d'attache vers l'identité Core : adhésion, profil, groupes, membres, rôles, événements et paiements. `/api/zumra/me` requête avec `session.entity`.

Le client Supabase métier fonctionne côté serveur avec `service_role`, sans session utilisateur Supabase (`persistSession=false`, `autoRefreshToken=false`, `detectSessionInUrl=false`).

Cette preuve ne valide aucun CAP ZUMRA futur.

## 5. Supabase Auth du back-office

Le Supabase Auth historique de `/admin` est classé credential du plan de contrôle CMS. Il n'est pas l'identité canonique d'un membre DG Afrique et ne doit jamais devenir la clé d'une adhésion, d'un groupe, d'un projet ou d'un satellite.
