# Preuves CAP-003 — PROFIL DE CAPACITÉS — 2026-08-11

> **État : EN DEV. Promotion production autorisée après build final READY ; validation utilisateur du parcours principal encore requise.**

## Référentiel

CAP-003 décrit une personne par ce qu'elle sait faire, souhaite apprendre et cherche à accomplir. Le profil est une source structurée d'orientation, pas une note de la personne.

## Contradiction corrigée

Avant CAP-003, `zumra_member_profiles` ne pouvait exister qu'avec `zumra_memberships`. Le profil DG était donc techniquement prisonnier de l'adhésion ZUMRA.

CAP-003 introduit `public.dg_person_profiles`, attaché directement à la référence d'identité canonique GAMAD Core et sans FK vers ZUMRA.

## Invariants sécurité / données

- l'identité de la ligne vient uniquement de `session.entity` ;
- le client ne choisit jamais `core_identity_reference` ;
- GET et PATCH vérifient la session courante auprès de GAMAD Core via `/sessions/current` ;
- le cookie portail n'est renouvelé qu'à l'échéance attestée Core ;
- PATCH est protégé same-origin ;
- champs historiques non affichés par l'éditeur courant sont préservés ;
- profil DG ≠ adhésion ZUMRA ;
- intentions libres DG ≠ intentions contrôlées d'adhésion ZUMRA ;
- aucun score global / pourcentage de valeur de la personne n'est affiché.
