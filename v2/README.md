# DG Afrique V2.0 — Laravel Super App foundation

This directory is the implementation workspace for DG Afrique V2.0.

## Product intent

DG Afrique is a public portal that becomes a contextual Super App after identity is known. The product is organized around capacities, poles, ZUMRA, projects and opportunities. GAMAD Core remains the canonical identity source.

## Stack

- PHP 8.4
- Laravel 13
- PostgreSQL
- Inertia.js
- React
- Tailwind CSS

## Phase 0

The first implementation slice contains:

- the Laravel/Inertia shell;
- public and authenticated home foundations;
- navigation shared by portal and app;
- the first design-system tokens;
- the four productive poles as first-class destinations;
- a ZUMRA network entry that deliberately leaves room for a future social activity layer focused on action rather than entertainment.

The current production Next.js application is not replaced by this directory. Migration remains controlled.
